# 1\. Purpose, Precedence, and the v0.4.7 Cross-System Carryforward Name

<!--@2¶1-->
“v0.4.7 Cross-System Carryforward” is the working name for the cross-system rulings first developed in the v0.4.7 Registers, Views, and Encounter Mode thread and retained after the v0.5 redesign. It is not a revival of v0.4.7 as active canon. It is a controlled salvage operation: keep the architectural decisions that make the new Home and Away specifications cohere; archive the assumptions those specifications have superseded.

<!--@2¶2-->
The original log was explicitly proposed rather than settled canon. This specification therefore does not preserve entries because they were marked SETTLED inside that log. It re-rules them against the v0.5 architecture.

<!--@2.1-->

<!--@3-->
# 2\. Executive Summary and Canonical System Statement

<!--@3¶1-->
The v0.5 redesign gives MEDIAN two highly developed halves: DWELL makes sanctuary mechanically achievable at Colony scale, while TRAVEL / RISK / MEET expose particular Citizens to distance and consequence. The v0.4.7 Cross-System Carryforward decisions provide the connective tissue that makes those halves feel like one game.

<!--@3.1-->
## What this specification governs

<!--@3.1¶1-->
  - When continuous Register play remains continuous and when the game fixes attention through MEET.

<!--@3.1¶2-->
  - How one authored situation can manifest differently in Home and Away contexts without becoming two systems.

<!--@3.1¶3-->
  - How named Citizens, Roles, Places, and whole-colony facts are selected for foreground representation.

<!--@3.1¶4-->
  - How unresolved Home situations persist without becoming an entropy treadmill or task inbox.

<!--@3.1¶5-->
  - How world facts remain singular while producing different consequences in DWELL, TRAVEL, RISK, MEET, and EMBODY.

<!--@3.1¶6-->
  - How personal lives remain descriptive and legible without citizen stat bars, morale meters, or ornamental gauges.

<!--@3.1¶7-->
  - How environmental pressure is staged over time and how visual backdrops preserve spatial continuity.

<!--@3.2-->
## Canonical system statement

<!--@3.2¶1-->
|                                                                                                                                                                                                                                                                                                            |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MEDIAN remains continuous and observable until a situation becomes bounded, consequential, and worthy of direct attention. MEET fixes that attention. The resulting choice acts upon one shared world state, then returns the player to a Register whose ordinary life visibly incorporates what occurred. |

<!--@4-->
# 3\. Register and View Architecture

<!--@3.1#2-->
## 3.1 Register definition

<!--@3.1#2¶1-->
A Register is MEDIAN’s complete visual and interactive contract for one kind of player attention. It governs framing, scale, time treatment, navigation, available controls, information hierarchy, Citizen representation, and the class of decision being asked for. A Register is not a geographic zone.

<!--@3.1#2¶2-->
| **Register** | **Verb** | **Primary attention**                                                          |
| ------------ | -------- | ------------------------------------------------------------------------------ |
| DWELL        | Dwell    | Sustain and observe collective life at Home.                                   |
| TRAVEL       | Travel   | Read territory, route, distance, load, shelter, and changing conditions Away.  |
| RISK         | Risk     | Act inside immediate embodied danger, especially Crossing.                     |
| MEET         | Meet     | Attend to a bounded circumstance and decide how the relevant subject responds. |
| EMBODY       | Embody   | Experience a Citizen’s lived scale within the safety of Home.                  |

<!--@3.2#2-->
## 3.2 View definition

<!--@3.2#2¶1-->
A View is a specific presentation built inside a Register. Views allow MEDIAN to create categorically different scenes without inventing a new mode for every presentation need.

<!--@3.2#2¶2-->
| **Register** | **Example Views**                                                                                                  |
| ------------ | ------------------------------------------------------------------------------------------------------------------ |
| DWELL        | Colony Overview View; Role and Readiness View; Project View; Place inspection.                                     |
| TRAVEL       | Home Reach View; Margin View; longitudinal Reach View; Stopover approach.                                          |
| RISK         | Staging View; outbound Crossing View; return Crossing View.                                                        |
| MEET         | Heavy Winds View; Base Defense View; Launch View; Homecoming View; contested Node View; uncontested resource View. |
| EMBODY       | Practice View; Presence View; species-specific Flow, Rest, Tend, or relationship moments.                          |

<!--@3.3-->
## 3.3 Register change test

<!--@3.3¶1-->
|                                                                                                                  |
| ---------------------------------------------------------------------------------------------------------------- |
| The Register changes because the player’s relationship to a place changes, not because the map location changed. |

<!--@3.3¶2-->
A berry bush is navigable geography in TRAVEL. It becomes MEET when a party decides what relationship to establish with it or when another Presence contests it. A Rabbit court is part of DWELL until Heavy Winds make its exposed shelter line a bounded decision. The same court may later become an EMBODY Presence scene once Quiet Equilibrium returns.

<!--@3.4-->
## 3.4 Anti-fragmentation rule

<!--@3.4¶1-->
New presentation needs should first be tested as Views inside an existing Register. A new Register is justified only when the player’s complete relation to time, scale, control, and subject changes. This rule did not prevent EMBODY; it explains why EMBODY qualified while Launch, Homecoming, Base Defense, and Road Work did not.

<!--@5-->
# 4\. The Attention Threshold: Native Information and MEET

<!--@4.1-->
## 4.1 Native information rule

<!--@4.1¶1-->
Routine facts remain in the Register that produced them. A pantry total changing, a Project completing, rain beginning, a Readiness Margin narrowing, or a Reach becoming slower does not by itself justify a modal scene.

<!--@4.2-->
## 4.2 MEET threshold

<!--@4.2¶1-->
A situation earns MEET when enough of the following are present:

<!--@4.2¶2-->
  - a genuine choice

<!--@4.2¶3-->
  - named or socially meaningful participation

<!--@4.2¶4-->
  - competing needs

<!--@4.2¶5-->
  - uncertain or costly outcome

<!--@4.2¶6-->
  - opportunity or danger

<!--@4.2¶7-->
  - persistent consequence

<!--@4.2¶8-->
  - a reason to stop surveying and attend

<!--@4.2¶9-->
|                                                                     |
| ------------------------------------------------------------------- |
| Information remains native. Consequential interaction becomes MEET. |

<!--@4.3-->
## 4.3 Why restraint matters

<!--@4.3¶1-->
The fixed MEET presentation is itself a promise: this moment deserves attention and may be remembered. If every small change seizes the camera, MEET loses dramatic weight and DWELL becomes an alarm dashboard. The threshold therefore protects both attachment-first play and successful stillness.

<!--@4.4-->
## 4.4 Chosen attention and arriving attention

<!--@4.4¶1-->
| **Origin Register** | **The player goes to it**                                                                     | **It comes to the player**                                                                                 |
| ------------------- | --------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| DWELL               | The player attends an open Place, Project, or known situation whose resolution requires MEET. | A Colony situation reaches the threshold and calls attention.                                              |
| TRAVEL              | The party enters a Node or deliberately approaches a known Presence.                          | A Field card or environmental interruption finds the party.                                                |
| RISK                | Not normally applicable; the Register is already direct embodied action.                      | Not normally applicable.                                                                                   |
| EMBODY              | No consequential MEET is nested inside an EMBODY experience.                                  | An urgent crisis ends eligibility or closes the experience rather than ambushing it with a decision modal. |

<!--@4.4¶2-->
The Field cadence guardrail remains: Nodes are the meal; cards are the weather. When interruptions become the principal content of travel, territory has stopped being readable.

<!--@6-->
# 5\. Choice Events and Persistent Situations

<!--@5.1-->
## 5.1 Choice Event as content packet

<!--@5.1¶1-->
The Choice Event is the authored content object. MEET is the runtime manifestation. The packet must be complete enough to appear in the correct View without depending on a literal card overlay.

<!--@5.1¶2-->
| **Packet field**       | **Required content**                                                                                                               |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Trigger                | World-state, calendar, pressure, route, Place, Node, relationship, or authored campaign condition.                                 |
| Origin                 | DWELL, TRAVEL, or a connector such as Launch / Homecoming.                                                                         |
| Situation family       | Environmental pressure, social claim, resource opportunity, Base Defense, arrival, personal incident, return, and so on.           |
| Scene requirements     | Location, backdrop, time, weather, season, active objects, and affected Places or Nodes.                                           |
| Subject                | Colony, Role, household, personal Citizen, or expedition party.                                                                    |
| Stakes                 | Primary stake, secondary stake, threatened value, and what changes if the player refuses.                                          |
| Response grammar       | Home MEET choice frame, uncontested Node grammar, contested Away Approaches, Launch, Homecoming, or another approved View grammar. |
| Costs and requirements | Resources, Citizen-Days, equipment, relationships, time, load, or role posture.                                                    |
| Consequences           | Group outcome, personal consequence where applicable, duration, escalation, Conditions, route or Place changes.                    |
| Memory                 | Campaign Memory / Chronicle language and later retrieval hooks.                                                                    |

<!--@5.2-->
## 5.2 Canonical lifecycle

<!--@5.2¶1-->
|                                                                                              |
| -------------------------------------------------------------------------------------------- |
| TRIGGER → SITUATION OPENS → MEET VIEW → RESPONSE → CONSEQUENCE → WORLD-STATE CHANGE → MEMORY |

<!--@5.3-->
## 5.3 A bounded scene is not always an instant resolution

<!--@5.3¶1-->
Home-origin situations may remain physically present after their first MEET View. A flooded pantry may reveal a restoration cost the Colony cannot yet meet. A damaged route may remain closed. A displaced household may continue occupying temporary space. The situation remains a scene with a known subject and state; it does not become a free-floating quest marker.

<!--@5.3¶2-->
| **Situation phase** | **Home-origin meaning**                                                                     |
| ------------------- | ------------------------------------------------------------------------------------------- |
| Open                | The problem becomes known and is visibly located in the Colony.                             |
| Remain open         | The player defers, lacks the required commitment, or chooses to tolerate the present state. |
| Escalate or change  | Elapsed time, season, or another event alters cost, scope, or affected Places.              |
| Close               | Action, deliberate inaction, or expiration resolves the situation.                          |
| Remember            | Significant outcomes enter Campaign Memory.                                                 |

<!--@5.4-->
## 5.4 Persistence guardrail

<!--@5.4¶1-->
Persistent Home situations must remain uncommon, local, and legible. They are not a replacement for continuous decay, a daily chore list, or a backlog of unresolved errands. Most competent domestic posture should continue to produce silent success.

<!--@5.4¶2-->
Away situations generally cannot be parked and resumed at leisure. The party is physically present, time is passing, and refusal or withdrawal is itself a resolution.

<!--@7-->
# 6\. Participant Scale and Relational Scene Composition

<!--@6.1-->
## 6.1 The subject determines representation

<!--@6.1¶1-->
| **MEET scale**         | **Crunch subject**                                                                                  | **Foreground representation**                                                 |
| ---------------------- | --------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Whole Colony           | Global Capacity, Load, materials, threatened Places, and time.                                      | Colony-state strip; no arbitrary fixed portrait lineup.                       |
| Standing Role          | One entrusted civic responsibility and its global capacity.                                         | Relevant Role-holder or adviser when the fiction benefits from a named voice. |
| Household / work group | A bounded set of Citizens sharing a Place, Practice, or immediate stake.                            | Only those affected.                                                          |
| Personal incident      | A particular Citizen is trapped, injured, responsible, uniquely committed, or personally addressed. | Full named Citizen treatment.                                                 |
| Away party             | The exact Citizens who chose to leave and whose individual state governs options and consequence.   | Every expedition participant.                                                 |

<!--@6.1¶2-->
|                                                                                                                           |
| ------------------------------------------------------------------------------------------------------------------------- |
| Named Citizens appear because the situation makes them relevant, not because the interface requires a fixed party lineup. |

<!--@6.2-->
## 6.2 Relational, not adversarial

<!--@6.2¶1-->
A MEET composition partitions the elements brought into consequential relationship. It does not imply combat or even opposition.

<!--@6.2¶2-->
| **Side A**           | **Relation**                       | **Side B**                      |
| -------------------- | ---------------------------------- | ------------------------------- |
| Colony               | must answer                        | Heavy Winds                     |
| Available labor      | must be committed against          | A threatened pantry             |
| Returning expedition | must be received by                | The Colony                      |
| Party                | must establish a relationship with | An uncontested wildflower field |
| Party                | must negotiate with                | A recurring animal Presence     |
| Rabbit court         | must endure or redirect            | Road Work pressure              |

<!--@6.3-->
## 6.3 Advisor voice

<!--@6.3¶1-->
A named adviser may interpret the threatened value in the language of the Colony without revealing exact success odds. This creates character exposure inside Colony-scale play while preserving the Colony as the mechanical subject.

# 7\. One World State Across Five Registers

<!--@7.1-->
## 7.1 Canonical doctrine

<!--@7.1¶1-->
|                                                                                                                                                      |
| ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Important facts belong to world state, not to a Register. A Register displays or acts upon those facts; it never creates a parallel version of them. |

<!--@7.1¶2-->
MEDIAN maintains one Citizen Record, one wound, one relationship, one Tool, one cargo state, one route, one Place condition, one Promise, and one Campaign Memory. The five Registers expose different consequences of those same facts.

<!--@7.1¶3-->
| **World fact** | **DWELL**                                       | **TRAVEL**                                            | **RISK**                                   | **MEET**                                              | **EMBODY**                                                        |
| -------------- | ----------------------------------------------- | ----------------------------------------------------- | ------------------------------------------ | ----------------------------------------------------- | ----------------------------------------------------------------- |
| Injured leg    | Reduces Role availability or creates Care Load. | Slows pace and narrows route options.                 | Makes timing and recovery harder.          | Changes available responses and personal consequence. | May shape a guided recovery Presence scene once safety exists.    |
| Critical cargo | Enters shared stores or a Project.              | Consumes carrying capacity and changes return burden. | Makes a Crossing harder to commit through. | May be protected, traded, yielded, or lost.           | May later appear as a familiar Place object or remembered detail. |
| Trusted Friend | Influences domestic presence and later memory.  | Changes willingness to travel or press onward.        | Shapes who returns for whom.               | Opens relational choices and consequences.            | Supports social Presence or Practice moments.                     |
| Damaged Place  | Creates Load, shortfall, or a Project need.     | May alter the route through Home Reach.               | May affect a Staging edge.                 | Becomes a bounded repair or protection situation.     | Blocks or changes experiences rooted in that Place.               |

<!--@7.2-->
## 7.2 Feature test

<!--@7.2¶1-->
For every proposed mechanic, ask: “Is this a new system, or a new situation produced by existing systems in another Register?” A separate surgery game, morale economy, or Homecoming inventory subsystem is presumptively wrong when wounds, Care, supplies, and allocation already exist as shared facts.

<!--@9-->
# 8\. Personal Information and Numerical Restraint

<!--@8.1-->
## 8.1 Shared logistics may be numerical

<!--@8.1¶1-->
Colony-scale facts such as Citizen count, Capacity, Load, Margin, stored resources, Citizen-Days, threatened Places, and Project progress may be expressed numerically because they are public shared logistics.

<!--@8.2-->
## 8.2 Individual lives remain descriptive

<!--@8.2¶1-->
Citizen condition is shown through named Conditions, descriptive bands, behavior, posture, animation, equipment, injury, and history. The interface does not reduce a Citizen to exposed health numbers or a second morale bar.

<!--@8.2¶2-->
| **Allowed personal information**                         | **Rejected substitute**                                |
| -------------------------------------------------------- | ------------------------------------------------------ |
| Healthy; Hurt; Maimed; recovering; unable to take a Role | 32 / 32 Health                                         |
| Shaken; grief; fear of a trigger; tharn                  | Spirit meter                                           |
| Trusted Friend; estranged; protective; dependent         | Relationship score                                     |
| Named wound and lasting impairment                       | Generic damage points                                  |
| Exposure state and widening consequence distribution     | A universal “danger bar” that duplicates other systems |

<!--@8.3-->
## 8.3 New meter burden of proof

<!--@8.3¶1-->
Every proposed group meter must be classified as either persistent state or a descriptive readout of existing state. Decorative quantities such as Party Unity, Community Resolve, Party Alarm, Party Calm, Negotiation Posture, or Harvest Outlook do not become new tracks merely because a prototype has room for them.

<!--@8.3¶2-->
|                                                                                            |
| ------------------------------------------------------------------------------------------ |
| Use numbers for shared logistics. Use language and visible condition for individual lives. |

<!--@10-->
# 9\. DWELL Attention States: Open and Called

<!--@9.1-->
## 9.1 Open DWELL

<!--@9.1¶1-->
Open is the ordinary domestic condition. The player may build, assign, observe, read, rearrange, inspect, linger, or enter EMBODY when eligible. Routine state does not seize the camera. A well-running Colony can remain here for meaningful stretches.

<!--@9.2-->
## 9.2 Called DWELL

<!--@9.2¶1-->
Called is the moment a Colony situation crosses the MEET threshold. Attention fixes on a bounded scene until the player responds, deliberately leaves the situation open, or accepts its consequence. Called is not a queue state; it is a specific event state.

<!--@9.2¶2-->
| **Open**                                                                           | **Called**                                                                      |
| ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| The player chooses where to look.                                                  | A specific circumstance has become too consequential to remain ambient.         |
| The Colony is legible as a continuous inhabited whole.                             | The camera and information hierarchy isolate the subject and stakes.            |
| Projects, stores, Roles, Places, and Citizens progress without modal interruption. | The player makes or defers a bounded decision.                                  |
| EMBODY may be available under Quiet Equilibrium.                                   | EMBODY is unavailable until the acute situation is resolved or safely deferred. |

<!--@9.2¶3-->
|                                                                                                                                |
| ------------------------------------------------------------------------------------------------------------------------------ |
| In TRAVEL, the player moves freely until they reach something. In DWELL, the player lives freely until something reaches them. |

<!--@9.3-->
## 9.3 Off-screen protection

<!--@9.3¶1-->
The attachment-first contract remains: MEDIAN does not take a named animal from the player off-screen. While attention is Away, Home may progress, improvise, gain something, or suffer inconvenience. A dangerous Home situation may open and wait. It may become more expensive or constrain more Places, but personal catastrophe is not resolved unseen.

<!--@9.3¶2-->
v0.5 correction: Home outcome depends on remaining Role headcount, Places, spatial alignment, stores, and Readiness—not on hidden differences in individual worker aptitude.

<!--@11-->
# 10\. Event Time: Telegraph, Impact, Persistence, and Aftermath

<!--@11¶1-->
Environmental events become clearer when written as phases rather than as one card that simultaneously warns, strikes, and repairs itself.

<!--@11¶2-->
| **Phase**      | **System meaning**                                                                                              | **Typical presentation**                                                                                           |
| -------------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Telegraph      | The world becomes legible before the full event. Preparation may still alter what will be at stake.             | Ambient signs in DWELL or TRAVEL; a Called Home MEET when a real preparatory choice exists.                        |
| Impact / Onset | The pressure actually strikes. Prior posture, Readiness, preparation, and unavoidable immediate action resolve. | Brief adjudication, animation, or direct RISK where appropriate; not a leisurely menu pretending time has stopped. |
| Persistence    | The event continues, shifts, or creates a second bounded decision.                                              | Home MEET, Away MEET, changed route terms, sustained Load, or a threatened Place.                                  |
| Aftermath      | What remains after the immediate pressure: damage, displacement, care, cleanup, memory, changed routes.         | Condition, Project, open Home situation, Homecoming consequence, or Campaign Memory.                               |

<!--@10.1-->
## 10.1 Phase integrity rule

<!--@10.1¶1-->
|                                                                                                                                                                              |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| If the player is offered a considered choice, the event has not fully struck yet, or it is still running. The blow itself is never disguised as a leisurely planning screen. |

<!--@10.2-->
## 10.2 Example: Heavy Winds

<!--@10.2¶1-->
| **Telegraph**                                                                  | **Impact**                                                              | **Persistence**                                                                                                                | **Aftermath**                                                                                                      |
| ------------------------------------------------------------------------------ | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| Reeds bend; lines hum; a Watchkeeper identifies the upper reach as vulnerable. | Unsecured coverings tear according to existing Builder / Watch posture. | The player spends one of two different commitments to preserve different stakes, or refuses and accepts the compounded result. | Upper rooms close; a repair Project opens; a Citizen may need care; later EMBODY scenes reflect the changed Place. |

<!--@12-->
# 11\. Base Defense and Home-Origin MEET

<!--@12¶1-->
Base Defense remains a Home-origin MEET family, not a separate tactical combat system. The Colony is the party. Its defense is expressed through prepared Places, species spatial grammar, Role Capacity, relevant weakness, materials, and the willingness to accept loss.

<!--@11.1-->
## 11.1 Canonical Home MEET grammar

<!--@11.1¶1-->
| **Option**                              | **Function**                                                                       |
| --------------------------------------- | ---------------------------------------------------------------------------------- |
| Protect the primary stake               | Spend one appropriate commitment to preserve the most important threatened value.  |
| Protect or redirect the secondary stake | Spend a different commitment to save, move, or transform another threatened value. |
| Commit neither                          | Preserve scarce capacity now and accept the compounded consequence.                |

<!--@11.1¶2-->
This grammar supersedes the old attempt to apply the five contested Away Approaches to storms, floods, structural failures, and Base Defense.

<!--@11.2-->
## 11.2 Personal consequence at Home

<!--@11.2¶1-->
A Home MEET may become personal when the fiction genuinely places a Citizen in danger. It may produce injury, fear memory, displacement, grief, or death. It does not ordinarily become a second Citizen-growth engine.

<!--@11.2¶2-->
| **Outcome**              | **v0.5 ruling**                                                                                                                                                 |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Domestic courage         | May enter Campaign Memory, a Tale, later dialogue, or an EMBODY scene.                                                                                          |
| Maiming / fear memory    | Possible when a particular Citizen is genuinely exposed in a severe Home event.                                                                                 |
| Distinction / After-name | Primarily belongs to individually resolved Away responsibility. Domestic exceptions require authored story justification rather than routine mechanical access. |

<!--@13-->
# 12\. Spatial Fidelity and Encounter Backdrops

<!--@12.1-->
## 12.1 Known-place doctrine

<!--@12.1¶1-->
A MEET backdrop is a consequential rendering of a Place already established in DWELL or TRAVEL. It preserves the player’s mental map while changing framing, time, weather, inhabitants, and state.

<!--@12.1¶2-->
| **Origin**                 | **MEET rendering**                                                                                   |
| -------------------------- | ---------------------------------------------------------------------------------------------------- |
| Rabbit court in DWELL      | The same court under wind pressure, with threatened roofline and covered exits labeled in the scene. |
| Wildflower Node in TRAVEL  | The same field as an uncontested resource choice or contested claim.                                 |
| Home edge / Staging ground | Launch and Homecoming share a legible axis and opposite emotional direction.                         |
| Held Reach shelter         | A Stopover, request for aid, or outpost consequence uses the same established shelter footprint.     |

<!--@12.2-->
## 12.2 Backdrop economy

<!--@12.2¶1-->
This doctrine is both spatial canon and production discipline. Registers should feel categorically different without each becoming a feature-complete standalone genre. Re-lighting and re-populating known places allows MEET to be visually rich without creating disconnected scene geography.

<!--@12.3-->
## 12.3 Strategic transparency

<!--@12.3¶1-->
Colony art remains operationally legible even where roofs, walls, brush, or foliage would conceal the world diegetically. “Open to the player” is not “open to the world.” Spatial fidelity concerns the implied Place and its relationships, not literal camera occlusion.

<!--@14-->
# 13\. Authoring and Presentation Doctrine

<!--@13.1-->
## 13.1 Environmental labels belong in the scene

<!--@13.1¶1-->
Functional labels such as Exposed Roofline, Open Grass, Loose Coverings, or Swaying Ladder should point into the rendered Place. They describe terrain and stakes without creating a tactical positioning grid.

<!--@13.2-->
## 13.2 Terrain changes price, not menu

<!--@13.2¶1-->
Away terrain may change the difficulty, consequence, or Exposure associated with an Approach. It does not create citizen-by-citizen positioning, facing, initiative, or targeting. The party remains one body on the front end; individuality resolves on the back end.

<!--@13.3-->
## 13.3 Canonical examples use canonical people

<!--@13.3¶1-->
Worked examples, concept plates, and system vignettes must draw from approved colony and Citizen banks. Reusing one name for different Citizens, inventing an unapproved roster for convenience, or allowing a concept image to establish new canon causes avoidable drift.

<!--@13.4-->
## 13.4 Visual invention does not establish canon

<!--@13.4¶1-->
Concept art may explore composition, material culture, weather, and mood. New Places, species, objects, structures, and mechanics become canon only through approved design text and designated reference plates.

<!--@13.5-->
## 13.5 Situation-state prototype requirement

<!--@13.5¶1-->
A MEET chassis is not proven by entry-choice screens alone. Before large-scale authoring, representative situations should be demonstrated across their full state sequence:

<!--@13.5¶2-->
  - Approach or Home-choice state

<!--@13.5¶3-->
  - Turn or persistence state

<!--@13.5¶4-->
  - personal consequence or tharn interrupt where applicable

<!--@13.5¶5-->
  - aftermath / open situation state

<!--@13.5¶6-->
  - return to native Register with changed world state

<!--@15-->
# 14\. v0.5 Revisions to Specific v0.4.7 Cross-System Carryforward Rulings

<!--@14.1-->
## 14.1 Ambient warning and Guest boundary

<!--@14.1¶1-->
The old log’s useful insight is retained at a high level: warnings should emerge through living behavior and environmental change rather than abstract countdown timers. A recurring resident may refuse to settle; a ground-dwelling neighbor may appear on high ground; a familiar animal may behave at the wrong hour.

<!--@14.1¶2-->
The old hard economy of four Guest slots divided into “warning” and “capability” modules is not carried forward here. Guest Citizen identity, residence, limits, relationships, and mechanical contribution require the dedicated v0.5 Guest Citizen pass. This specification preserves only the diegetic-warning principle.

<!--@14.2-->
## 14.2 Outpost identity after the Away rework

<!--@14.2¶1-->
The old ruling that a Held Reach carries partial Home Mode is superseded. An outpost remains Away: a refuge, Stopover, low Care point, Watch point, cache, and place to end a leg. It does not support DWELL or EMBODY as an alternate Colony.

<!--@14.2¶2-->
|                                                                |
| -------------------------------------------------------------- |
| An outpost gives you the roof. It never gives you the village. |

<!--@14.2¶3-->
The older emotional and species observations remain useful as worldbuilding: Mouse experiences a room that touches nothing; Rabbit experiences frontage without Company; Squirrel experiences a node with insufficient redundancy. These shape scenes and fears, not a second domestic ruleset.

<!--@14.3-->
## 14.3 Multi-day focus switching

<!--@14.3¶1-->
The old “leg is the unit of Away focus” proposal remains unresolved under v0.5. A multi-day journey may need to cut back to Dawn at Home while the party rests at a Stopover, but the exact player authority, EMBODY eligibility, and treatment of continuing absence are not yet canonical. This belongs to the Corridor and Frontier Progression pass.

<!--@14.4-->
## 14.4 Corridor narrative orientation

<!--@14.4¶1-->
The qualitative campaign geography survives strongly: down-corridor leads toward the ruined ancestral home and the weight of the past; up-corridor leads toward the Rest-Stop Metropolis and a possible civic future. The corridor continues beyond both.

<!--@14.4¶2-->
|                                                                                         |
| --------------------------------------------------------------------------------------- |
| A colony can go back and look at what it lost before it can reach what it might become. |

<!--@14.4¶3-->
Exact numbers of Reaches, Reaches per day, and required outposts remain prototype values, not fixed canon.

<!--@14.5-->
## 14.5 No generic expedition Rating

<!--@14.5¶1-->
The old unresolved question of whether every Encounter receives a Legendary / Successful / Hard-Earned / Failed grade is closed by the Away rework: there is no generic expedition grade. Memory should preserve what was achieved, paid, changed, and carried home rather than flattening the journey into one score.

# 17\. Canon Rules, Non-Goals, and Acceptance Tests

<!--@17.1-->
## 17.1 Canon rules

<!--@17.1¶1-->
  - A Register is a mode of attention; a View is a presentation within it.

<!--@17.1¶2-->
  - Routine information remains native; bounded consequential interaction becomes MEET.

<!--@17.1¶3-->
  - Choice Events are authored packets whose consequences change one shared world state.

<!--@17.1¶4-->
  - Home-origin situations may remain open, but persistence is rare, local, and never a substitute for continuous decay pressure.

<!--@17.1¶5-->
  - Participant representation follows the actual subject of the situation.

<!--@17.1¶6-->
  - MEET is relational rather than inherently adversarial.

<!--@17.1¶7-->
  - Personal lives are expressed through descriptive condition and history; shared logistics may be numerical.

<!--@17.1¶8-->
  - DWELL is Open by default and Called only by threshold-worthy situations.

<!--@17.1¶9-->
  - Environmental events distinguish Telegraph, Impact, Persistence, and Aftermath.

<!--@17.1¶10-->
  - Base Defense remains Home MEET, not a second combat game.

<!--@17.1¶11-->
  - MEET backdrops preserve the geography of known Places and Nodes.

<!--@17.1¶12-->
  - Concept art does not establish new canon without approved design text.

<!--@17.2-->
## 17.2 Non-goals

<!--@17.2¶1-->
  - A fifth economic subsystem for every View or Register.

<!--@17.2¶2-->
  - Modal interruption as the normal texture of domestic play.

<!--@17.2¶3-->
  - A generic event deck that makes the Colony feel like a place things only happen to.

<!--@17.2¶4-->
  - Tactical positioning, initiative, facing, or targeting inside MEET.

<!--@17.2¶5-->
  - Citizen health numbers, Spirit bars, or decorative group meters.

<!--@17.2¶6-->
  - Using named Citizens as interface furniture when the Colony is the actual subject.

<!--@17.2¶7-->
  - Portable Home Mode at outposts or calm Away locations.

<!--@17.2¶8-->
  - Guest species treated as four-slot warning and capability modules before their dedicated design pass.

<!--@17.3-->
## 17.3 Acceptance tests

<!--@17.3¶1-->
| **Test**                 | **Pass condition**                                                                                                                                       |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Attention test           | A player can distinguish ambient information from a true MEET without relying only on labels.                                                            |
| Stillness test           | A competent Colony can remain in Open DWELL without continuous forced events.                                                                            |
| Subject test             | A whole-Colony event does not display arbitrary expedition portraits, and a personal event does not dissolve the Citizen into a generic capacity number. |
| Persistence test         | An unresolved Home situation remains visible and meaningful without creating an ever-growing task backlog.                                               |
| World-state test         | The same wound, relationship, cargo object, Place condition, and route remain consistent across every Register.                                          |
| Numerical-restraint test | No Citizen screen exposes health numerals, Spirit, or redundant personal meters.                                                                         |
| Temporal test            | The player can tell whether an environmental event is being telegraphed, striking, persisting, or leaving aftermath.                                     |
| Backdrop test            | A MEET scene remains recognizably the same Place or Node the player knew before attention fixed upon it.                                                 |
| Attachment test          | The interface makes the player attend to threatened lives and Places without converting them into replaceable production assets.                         |
| Guest-boundary test      | The document’s rules remain valid without deciding detailed Guest species capabilities.                                                                  |

<!--@19-->
# Final System Statement

<!--@19¶1-->
|                                                                                                                                                                                                                                                                                                           |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The v0.4.7 Cross-System Carryforward are the shared grammar by which MEDIAN changes scale without changing reality. DWELL, TRAVEL, RISK, MEET, and EMBODY do not own separate versions of the world. They are five ways of attending to the same Colony, corridor, Citizens, Places, injuries, promises, and memories. |

<!--@19¶2-->
The practical sequence is simple: ordinary Registers reveal the world; threshold-worthy circumstances call MEET; MEET fixes attention on the appropriate subject; consequences alter shared world state; the player returns to ordinary life and sees what changed. This architecture lets Home remain lingerable, Away remain consequential, and attachment remain the reason the systems matter.
