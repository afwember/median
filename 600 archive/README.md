# Archive

Superseded project material and retired process machinery are retained here for
history, provenance, and occasional recovery. Nothing in this directory is an
active operating control or current canon merely because it has been preserved.

## Main contents

- Earlier GDD editions and absorbed development material preserve design
  lineage and rejected alternatives.
- Historical threads and planning documents preserve reasoning that may outlive
  an individual decision.
- `m050-information-management/` preserves the complete retired v0.5.0
  extraction-through-reconciliation system at its final stopped checkpoint.

Use archived material deliberately and narrowly. A superseded document can look
authoritative, and retired process controls can look executable. Current work is
defined by root `AGENTS.md`, canonical compile state, and the active files named
there.
