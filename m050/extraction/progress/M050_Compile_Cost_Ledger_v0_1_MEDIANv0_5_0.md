## Maintenance rule

Add one row for every future paid request or provider batch, including failed
and rejected requests. Record the provider receipt when available. If only a
budget cap or estimate is known, keep it outside confirmed spend until billing
reconciliation. Update the three totals above whenever an entry changes.

exact API surface in `service`, the exact returned model identifier in `model`,
and whether the charge came from a synchronous request or Batch API job in
`execution_mode`. Anthropic and OpenAI costs then contribute to the same
confirmed total while retaining provider-level traceability.
