# MEDIAN Task Handoff

This is the safe entry point for a replacement task or for recovery after
context compaction. Do not load the historical transcript unless a specific
question remains unresolved after reading current evidence.

## Bootstrap prompt

Copy the following into a replacement MEDIAN task:

> Continue MEDIAN operations from the canonical continuity package in
> `m050/docs/operations/continuity/`. Read `README.md`, `CURRENT_STATE.md`,
> `NEXT_ACTION.md`, `DECISIONS.md`, and `OPERATIONS.md` completely. Then run the
> read-only `./m050/tools/m050_verify_mac_mini.sh` check and inspect Git status,
> local HEAD, and `origin/main`. Report the reconstructed operating picture,
> discrepancies, and proposed next action to me before making changes. Treat my
> latest explicit instruction and current repository evidence as authoritative.
> Do not load the full historical thread export unless a named ambiguity
> requires a targeted search. Do not make paid provider calls without a new,
> exact authorization.

## Required reconstruction report

Before changing state, the receiving task must identify:

- current project gate and completion boundary;
- exact immediate next action and stop conditions;
- local branch, HEAD, upstream alignment, and worktree state;
- Mac Mini operating-system and remote-access state;
- whether any reboot, provider request, or other operation is in flight;
- current cost rule and whether paid work is authorized;
- any mismatch between documents and live evidence.

## Handoff acceptance

The handoff is successful only when the receiving task's report agrees with the
canonical records and live checks, or when discrepancies have been explicitly
resolved. Keep the originating task available until that test passes.
