# MEDIAN Artwork

`Median-Book.jpg` is the repository's readily accessible splash image.

Curated artwork is catalogued under `art-manifest/`. The repository stores a
low-resolution thumbnail for each catalogued work; its full-resolution source
is stored externally at the manifest's `full_res_url`. New entries are added
selectively through the MEDIAN Dropper workflow.

Full-resolution working art and historical art collections do not belong in
Git history.
